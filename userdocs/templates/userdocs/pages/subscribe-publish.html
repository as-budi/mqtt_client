Everything on the connection page runs in your browser. Press Connect first; the status in the header shows Connecting…, Connected, Reconnecting… or Not connected with the reason.

Connecting and reconnecting

  • When the connection drops, the page tries again after 1, 2, 5, 10, 20 and then every 30 seconds, and subscribes again.
  • It does not retry when trying again cannot help: wrong username or password, not authorised, an address the relay may not reach, or a certificate problem. The reason is shown above the page.
  • Disconnect closes the connection; closing the tab does the same.

Subscriptions

Type a topic filter (wildcards allowed), choose a QoS and press Subscribe. Each subscription shows its state:

MarkMeaning
✓accepted by the broker
…waiting (not connected yet)
refusedthe broker does not allow this filter for your login (for example another device's topic on IoT Platform)

mute hides the messages of a subscription (they are still received; show brings them back); ✕ unsubscribes.

Publishing

  1. Type the topic (suggestions come from your history and the device topics). Wildcards are not allowed.
  2. Write the payload. Choose Text or JSON: JSON is checked before sending, and Format indents it.
  3. Choose QoS and Retain, then Publish or press Ctrl+Enter (⌘+Enter on a Mac).

The JSON editor

With the JSON format, the payload box works like a small code editor: line numbers, colours for keys and values, the line of a JSON error marked in red, Tab inserts two spaces and Enter keeps the indentation. Preview shows the result with placeholders filled in, folded like the message viewer.

Placeholders

Placeholders in the topic or payload are replaced every time a message is sent:

PlaceholderExample result
{% templatetag openvariable %}counter}}1, 2, 3, … (messages sent from this page)
{% templatetag openvariable %}timestamp}}2026-10-22T07:57:40.302Z
{% templatetag openvariable %}unix}}1792655860 (seconds since 1970)
{% templatetag openvariable %}random:20:30}}27.86 (two decimals)
{% templatetag openvariable %}int:0:100}}42
{% templatetag openvariable %}bool}}true or false

Example: {"temperature": {% templatetag openvariable %}random:20:30}}, "n": {% templatetag openvariable %}counter}}}. A placeholder without quotes counts as a number when the JSON is checked.

Publishing repeatedly

In the Automation card, Publish the message above every N s → Start sends the Publish card's message again and again (at least every second) until Stop, until the connection is lost, or until you leave the page. Placeholders change each time, so this is an easy sensor simulator.

History, saved messages and retained messages

  • History: the last 20 messages you published, kept in this browser.
  • Save / Saved: messages kept in your account (at most {{ max_saved }}), for this connection or, with Available in all my connections, for every connection.
  • Clear retained: publishes an empty retained message to the topic, which removes the retained message on the broker (you are asked to confirm).
