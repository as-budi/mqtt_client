The right side of the connection page shows the traffic of this visit: messages you receive (↓) and publish (↑). Nothing is sent to this server; the messages disappear when you close the page, unless you export them.

The message list

  • Newest first, with topic, QoS, size, time and a retained mark. The stripe on the left has the colour of the matching subscription.
  • Filter (press / to jump there) matches topic or text; All / Received / Published limits the direction.
  • Pause stops drawing new messages (they are still collected); Clear empties the list.
  • Each message has Copy topic, Copy payload and Publish again (fills the Publish card).
  • The page keeps the last 2,000 messages and draws the last 500 that pass the filter.

Payload views

ViewShows
AutoJSON objects and arrays in the JSON viewer, anything else as text
JSONthe JSON viewer, or (not JSON)
Text, Hex, Base64the raw bytes as text, hexadecimal or base64 (useful for binary payloads)

The JSON viewer has line numbers, colours and buttons to fold each object or array; long JSON also gets Expand all / Collapse all. Payloads are always shown as text: HTML or scripts inside a message are never run.

Topic tree

The Topics tab arranges every topic seen by its levels, with the number of messages and the last value at each leaf. Click a topic to go back to the list filtered on it.

Charts

The Charts tab draws a small line chart for every series of numbers: a payload that is a number (23.5), or each number or true/false key in a JSON object ({"temperature": 23.5} becomes topic › temperature). Messages you publish are included, so simulated telemetry shows up too. Each chart shows the last value, minimum, maximum and the last 120 points.

MQTT 5 properties

For profiles using MQTT 5, the Publish card has an MQTT 5 properties section:

FieldUse
Content typetells receivers the payload format, e.g. application/json
Expiry (s)the broker drops the message (also a retained one) after this many seconds
Response topicrequest/response: the receiver answers on this topic
User propertiesfree key=value pairs, one per line

Properties of received messages are shown in the message's info line.
