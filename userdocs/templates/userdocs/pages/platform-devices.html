Connections → From IoT Platform lists the devices you own and those shared with you on IoT Platform, and your MQTT sandbox account.

Connecting as a device

Create connection next to a device makes a profile that:

  • uses the IoT Platform broker{% if platform_ws %} ({{ platform_ws }}){% endif %};
  • logs in as the device (username and password = its access token);
  • subscribes to the device's desired, commands/+, errors and rules/+ topics.

You need the Editor role on a shared device (owners always can); Viewers and Operators see the device but cannot connect as it. The access token is not stored here: it is fetched from IoT Platform every time you connect, so the profile keeps working after the token is regenerated.

The profile shares its identity with the real device. Everything you publish is accepted by IoT Platform as if the device sent it: it appears on the dashboard, can trigger rules and is kept in the history.

Device topics

On the connection page, the Device topics buttons fill the Publish card with a topic and an example payload:

ButtonTopicWhat IoT Platform does with it
Telemetry…/telemetrystores the values of the device's variables
Online…/statusshows the device online or offline
Firmware…/firmwarerecords version, board and MAC address
Command response…/commands/<id>/responsecompletes a command (replace <id>)
Rule ack…/rules/<id>/ackconfirms a rule JSON received from Publish to devices

The MQTT sandbox

The sandbox is a personal MQTT account on the IoT Platform broker, for practising without a device. Create it on IoT Platform (Profile → MQTT sandbox), then come back to From IoT Platform and choose Create connection in the sandbox card.

TopicsWho
sandbox/<your username>/#only you
sandbox/public/#shared by every sandbox user

The sandbox password is not stored here; it is fetched from IoT Platform on every connect. In a sandbox profile, topics may use {sandbox}, which becomes sandbox/<your username>. The Sandbox topics buttons fill the Publish card with examples. Messages in the sandbox are not stored by IoT Platform and do not appear on dashboards.
